## 案例一：数字化城市管理项目（数据治理 + 风险管理）

### 问题1（10分）：项目存在的问题和风险

<details>
<summary>查看参考答案</summary>

**问题：**

1. **经验不匹配**：A公司过去做银行信息系统，从未做过城市管理项目，缺乏行业经验，承接该项目存在较大能力风险。
2. **多部门协调难度大**：城市管理牵涉多个政府部门，协调管理复杂，但项目计划中未见相应的协调机制设计。
3. **数据标准缺失**：现有数据来自各部门、标准不统一、多源异构，数据整合难度极大，需建立数据元标准，但这本身就是一个复杂工程。
4. **项目周期过长**（8年），需求可能在8年间发生重大变化，项目范围难以稳定。
5. **顶层设计不足**：项目在A公司参与前，各部门已独立建设，缺乏统一顶层规划，后期整合成本高。

**风险：**

1. **技术风险**：A公司缺乏城市管理领域经验，对交通数据等专业领域的技术掌握不足，实施过程可能出现重大技术障碍。
2. **数据整合风险**：多源异构数据整合难度高，数据质量难以保证，影响系统有效性。
3. **政治/政策风险**：政府重点项目涉及多个政府部门，部门间利益协调可能导致项目停滞或范围变更。
4. **进度风险**：8年建设期内，人员流动、需求变更、技术演进可能导致项目严重超期。
5. **合规风险**：数据元标准化工作若与国家标准不一致，可能面临合规问题。

</details>

### 问题2（5分）：数据元与制定标准的过程

<details>
<summary>查看参考答案</summary>

**什么是数据元（Data Element）：**

数据元是通过定义、标识、表示以及允许值等一系列属性描述的数据单元。数据元是不可再分的最小信息单元，是构建数据标准的基础组件。

**制定数据元标准应遵循的过程：**

1. **需求分析**：收集和分析各部门的数据需求，梳理现有数据资源和问题。
2. **数据元调研**：调研国内外相关标准（国家标准、行业标准），避免重复制定。
3. **数据元设计**：对每个数据元定义名称、标识符、定义、数据类型、表示格式、允许值等属性。
4. **评审与验证**：组织相关部门和专家对数据元标准草案进行评审，验证其适用性。
5. **标准发布**：经审批后正式发布，成为约束各系统的规范文件。
6. **标准维护**：随业务发展定期评审和更新数据元标准。

</details>

### 问题2（5分）：H活动延期分析

<details>
<summary>查看参考答案</summary>

**H活动的总时差计算：**

- ES(H) = ES(D) + dur(D) = ES(A) + dur(A) + dur(D) = 0+3+4 = **7天**
- EF(H) = 7+3 = 10天
- LF(H) = LF(K) - dur(K) = 17-5 = 12天
- LS(H) = LF(H) - dur(H) = 12-3 = 9天
- **TF(H) = LS - ES = 9 - 7 = 2天**

**结论：H活动有2天的总时差，说法"一旦延期将影响整个项目工期"是错误的。**

H活动延期 **1-2天** 不影响总工期；延期 **超过2天** 才会影响整个项目工期。

具体：若H延期3天（超过总时差2天），将影响整个项目工期，导致项目延迟1天。

</details>

### 问题4（3分）：项目经理应采取的措施

<details>
<summary>查看参考答案</summary>

1. **分析落后原因**：H、K未开工，I、J进度只有50%，需找出落后的根本原因。
2. **赶工（Crashing）**：为I、J等关键活动增加资源，加快完成。
3. **快速跟进（Fast-Tracking）**：合理调整活动执行顺序，并行处理部分工作。
4. **更新进度计划**：重新评估剩余工作，制定追赶方案，明确恢复进度的里程碑。
5. **加强监控**：加大对关键路径活动的监控频率，及时识别新的风险。

**资源管理方面：**

### 问题4（5分）：项目资源管理包含的过程

<details>
<summary>查看参考答案</summary>

| 过程 | 主要作用 |
|-----|--------|
| **规划资源管理** | 确定如何识别、获取、管理和使用项目资源，建立资源管理计划 |
| **估算活动资源** | 估算完成项目工作所需的团队和实物资源的类型、数量 |
| **获取资源** | 获取项目所需的团队成员、设施、设备、材料等 |
| **建设团队** | 提升团队成员的能力和协作水平，改善团队氛围，提高项目绩效 |
| **管理团队** | 跟踪团队绩效，解决问题，管理变更，提供绩效反馈 |
| **控制资源** | 确保实物资源按计划分配使用，监控实际资源与计划的偏差并采取纠正措施 |

</details>
