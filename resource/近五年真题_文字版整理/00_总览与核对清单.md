## 综合知识格式说明

每道选择题按以下格式呈现：

```
### 第N题 【知识点分类】

**题目：** 完整题干（含括号填空）

A、选项A文字
B、选项B文字
C、选项C文字
D、选项D文字

**答案：X — 答案文字**

**解析：** 解析内容

---
```

## 注意事项

1. **2020–2023上**：真题为完整版（非回忆版），题目质量较高。
2. **2023下、2024上**：为考生回忆版，部分题目表述可能与官方原题有差异。
3. **含图表题目**：PDF 中表格数据由 PyMuPDF 文字层提取，如提取不完整，请参考原始 PDF 图片。
4. **答案来源**：均来自仓库内已有的 `综合知识_答案解析.md` / `案例分析_答案解析.md`，非官方标准答案。
