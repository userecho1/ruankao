## 案例一：政府数字化项目（采购管理 + 变更管理 + 成本管理）

### 问题1（10分）：项目管理存在的问题

**采购管理方面：**
1. 供应商选择标准不完善，仅凭价格低选择分包商，未评估分包商的技术能力和实施经验。
2. 合同中缺少对分包商的绩效考核条款，无法通过合同约束分包商按质按量完工。
3. 未建立对分包商的定期监控机制，导致分包商进度滞后时项目经理未能及时发现。

**变更管理方面：**
1. 项目在实施过程中出现多次需求变更，但未通过变更控制委员会（CCB）正式审批，变更直接执行。
2. 变更未同步更新项目基准（范围基准、进度基准、成本基准），导致基准失去参考意义。
3. 缺少变更影响评估，每次变更对进度和成本的影响未进行量化分析。

**成本管理方面：**
1. 未建立成本基准，无法对项目成本进行有效监控。
2. 预算分配不合理，预留管理储备比例偏低，无法应对大量变更带来的成本超支风险。
3. 缺少挣值管理（EVM）等成本绩效监控手段，成本偏差发现滞后。

---

### 问题2（8分）：变更控制流程

**规范的变更控制流程：**

1. **提交变更申请**：由变更发起人（客户/团队成员）填写变更请求表，说明变更原因、变更内容和预期收益。
2. **变更请求登记**：项目经理将变更请求记录到变更日志，分配编号，跟踪处理状态。
3. **变更影响评估**：项目经理组织技术和计划人员评估变更对范围、进度、成本、质量、风险的影响。
4. **CCB审批决策**：变更控制委员会基于评估结果，决定批准、拒绝或推迟变更。
5. **通知申请人**：将审批结果告知变更申请人，并说明理由。
6. **制定变更实施计划**：对批准的变更，制定详细实施计划，更新项目管理计划和项目文件。
7. **执行变更**：按计划落实变更，实施过程中跟踪和控制。
8. **验证和关闭**：确认变更结果，更新变更日志并关闭该变更请求，归档相关文件。

---

### 问题3（7分）：成本管理知识点

**（1）成本管理计划包括的内容：**

1. 计量单位（各类资源的度量单位）
2. 精确度（估算的近似程度）
3. 准确度（估算可接受的范围）
4. 组织程序链接（与组织WBS结构的对应关系）
5. 控制临界值（允许偏差的阈值）
6. 绩效测量规则（如EVM测量方法）
7. 报告格式（成本报告的频率和格式）
8. 其他细节（如资金融通方式、汇率波动处理等）

**（2）直接成本与间接成本的区别：**

| 类型 | 定义 | 举例 |
|-----|------|------|
| **直接成本** | 可直接归属到具体项目工作的成本 | 项目人员工资、设备采购费、材料费、差旅费 |
| **间接成本** | 由多个项目共同承担、无法直接归属单一项目的成本 | 管理费用、水电费、租金、公共设施费 |

## 案例二：医疗信息系统项目（质量管理 + 沟通管理）

### 问题1（10分）：质量管理问题分析

**质量管理方面存在的问题：**

1. **质量标准不明确**：项目启动时未与客户明确系统质量验收标准，导致后期对质量的理解存在分歧。
2. **质量规划不足**：未制定质量管理计划，缺少质量保证和质量控制的具体措施。
3. **测试不充分**：仅进行了功能测试，未进行性能测试、安全测试、压力测试，上线后出现性能问题。
4. **缺少质量审计**：未定期进行质量审计，无法识别系统性质量隐患。
5. **用户验收测试（UAT）不规范**：未组织系统性的用户验收测试，用户对功能的验证不完整。
6. **问题跟踪机制缺失**：测试发现的问题未统一登记和跟踪，部分问题修复后未复测验证。

---

### 问题2（6分）：质量管理的三个过程

| 过程 | 主要工作 | 目的 |
|-----|--------|------|
| **规划质量管理** | 识别质量要求，制定质量标准和验收标准，编制质量管理计划 | 明确"达到什么质量" |
| **管理质量**（质量保证） | 审计质量管理过程，确保质量政策和程序被正确执行 | 过程符合质量要求 |
| **控制质量** | 对可交付成果进行检查和测量，识别缺陷，处理质量问题 | 成果满足质量标准 |

---

### 问题3（9分）：沟通管理存在的问题和干系人管理建议

**沟通管理存在的问题：**

1. **沟通渠道不规范**：客户人员直接联系开发人员提需求，信息未通过项目经理汇聚，沟通混乱。
2. **缺少定期项目状态报告**：未定期向客户发送进度报告，客户对项目状态了解不足，信任度低。
3. **会议效率低下**：会议缺乏议程，无会议纪要，决策结论未形成书面记录。
4. **沟通计划缺失**：未制定沟通管理计划，不同干系人的沟通频率和方式没有规定。
5. **反馈机制缺乏**：客户意见未及时收集和响应，客户满意度低。

**干系人管理建议：**

1. 识别所有关键干系人（客户、医院管理层、医护人员、项目团队、监管部门），建立干系人登记册。
2. 分析各干系人的关注点、影响力和参与程度，制定针对性的沟通策略。
3. 定期向高层干系人汇报项目状态，对核心用户定期演示功能进展。
4. 建立干系人反馈渠道，及时处理干系人的关切和诉求。

### 挣值管理基础公式（备查）

| 指标 | 公式 | 含义 |
|-----|------|------|
| SV（进度偏差）| EV - PV | >0进度超前，<0落后 |
| CV（成本偏差）| EV - AC | >0成本节省，<0超支 |
| SPI（进度绩效指数）| EV / PV | >1超前，<1落后 |
| CPI（成本绩效指数）| EV / AC | >1节省，<1超支 |
| ETC（完工尚需成本）| (BAC - EV) / CPI | 典型偏差假设持续 |
| EAC（完工估算）| AC + ETC | 预计最终总成本 |
| VAC（完工偏差）| BAC - EAC | 预计节省/超支 |
