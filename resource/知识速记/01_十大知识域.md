# 十大知识域 + 五大过程组 速记

---

## 五大过程组

| 过程组 | 核心动作 |
|--------|----------|
| 1. 启动 | 授权立项，识别相关方 |
| 2. 规划 | 制定各类管理计划，建立基准 |
| 3. 执行 | 按计划实施，管理团队与沟通 |
| 4. 监控 | 跟踪偏差，实施变更控制 |
| 5. 收尾 | 验收交付，归档，释放资源 |

---

## 十大知识域

### 1. 项目整合管理

核心地位：协调所有知识域，贯穿全生命周期，是项目经理的核心职责。

关键过程：制定项目章程 → 制定项目管理计划 → 指导与管理项目执行 → 管理项目知识 → 监控项目工作 → **实施整体变更控制** → 结束项目或阶段

高频考点：
- 变更控制委员会（CCB）审批变更
- 整体变更控制流程（申请→评估→CCB审批→执行→记录）
- 项目经理无权单独批准重大变更
- 配置管理：配置识别→配置控制→配置状态报告→配置审计

---

### 2. 项目范围管理

关键工具：WBS（工作分解结构）、需求跟踪矩阵

高频考点：
- WBS最低层是**工作包**，工作包可进一步分解为活动
- **范围蔓延**：未经批准的范围变更（应避免）
- **确认范围**（监控组）= 甲方验收，关注是否"完成"
- **控制范围**（监控组）= 防止范围蔓延，关注是否"变更"
- 产品范围 vs 项目范围的区别

---

### 3. 项目进度管理

关键工具：关键路径法（CPM）、甘特图、网络图、资源平衡

高频考点：
- **关键路径**：网络图中最长路径，总浮动时间 = 0
- 总浮动时间 = 最晚完成 - 最早完成（关键路径上为0）
- 自由浮动时间 = 紧后活动最早开始 - 本活动最早完成
- **赶工（Crashing）**：增加资源，成本增加，用于关键路径
- **快速跟进（Fast Tracking）**：并行，增加风险，不增成本
- **PERT三点估算**：期望值 = (O + 4M + P) / 6；标准差 = (P-O)/6

---

### 4. 项目成本管理

关键工具：挣值管理（EVM）

> 详见《挣值计算公式》文件

高频考点：
- 成本基准 = 经批准的分时段项目预算（不含管理储备）
- 应急储备：应对已识别风险（已知-未知），项目经理可动用
- 管理储备：应对未识别风险（未知-未知），需高层批准

---

### 5. 项目质量管理

关键工具：

| 过程 | 工具 |
|------|------|
| 规划质量 | 成本效益分析、质量成本、标杆对照 |
| 管理质量（质量保证） | 审计、过程分析 |
| 控制质量 | 检查、帕累托图、控制图、因果图（鱼骨图）、散点图、流程图 |

高频考点：
- **质量成本** = 一致性成本（预防+评价）+ 非一致性成本（内部失败+外部失败）
- **质量保证**（执行过程组）：面向过程，预防缺陷
- **质量控制**（监控过程组）：面向产品，发现缺陷
- **金镀（Gold Plating）**：超出范围添加功能，应当避免
- 帕累托图（80/20法则）：找出引起80%问题的20%原因

---

### 6. 项目资源管理

关键工具：RACI矩阵（责任分配矩阵）、资源直方图

高频考点：
- **马斯洛需求层次**（从低到高）：生理→安全→社交→尊重→自我实现
- **赫茨伯格双因素**：
  - 激励因素（满足感）：成就感、认可、工作本身、晋升
  - 保健因素（不满足感）：薪资、工作环境、公司政策
- **冲突解决方式优先级**：合作/解决问题 > 妥协/调解 > 撤退/回避 > 强迫/命令
- **团队建设阶段**：形成→震荡→规范→成熟→解散（塔克曼阶梯理论）

---

### 7. 项目沟通管理

高频考点：
- **沟通渠道数公式**：n(n-1)/2（n=团队人数）
  - 例：5人团队 = 5×4/2 = 10条
- 沟通方式优先级（正式程度）：正式书面 > 正式口头 > 非正式书面 > 非正式口头
- 冲突、合同事项 → 正式书面
- 沟通障碍：语义歧义、文化差异、技术噪声、信息过载

---

### 8. 项目风险管理

过程：规划→识别→定性分析→定量分析→规划应对→实施应对→监督

风险识别工具：头脑风暴、德尔菲法、SWOT分析、检查单、假设条件分析

定量分析工具：蒙特卡罗模拟、决策树分析、敏感性分析（龙卷风图）

**风险应对策略（威胁）**：
| 策略 | 说明 |
|------|------|
| 回避 | 改变计划，消除风险（成本高） |
| 转移 | 转给第三方（保险、外包） |
| 减轻 | 降低概率或影响 |
| 接受（主动）| 制定应急计划 |
| 接受（被动）| 不做处理 |

**风险应对策略（机会）**：开拓、分享、提高、接受

高频考点：
- 风险登记册：记录所有已识别风险及其状态
- 残余风险：应对后仍存在的风险
- 二次风险：应对措施本身带来的新风险
- 应急储备（已知-未知）vs 管理储备（未知-未知）

---

### 9. 项目采购管理

合同类型（卖方承担风险从高到低）：

| 类型 | 风险在 | 说明 |
|------|--------|------|
| 固定总价（FFP） | 卖方 | 买方最安全 |
| 总价激励费用（FPIF） | 偏卖方 | 有激励条款 |
| 时间与材料（T&M） | 混合 | 混合型 |
| 成本加激励费用（CPIF） | 偏买方 | 有激励条款 |
| 成本加固定费用（CPFF） | 买方 | 卖方最安全 |

高频考点：
- 招投标程序：发标→投标→开标→评标→定标→签合同
- 评标委员会：5人以上单数，专家≥2/3
- 合同签署：中标通知书发出后30日内

---

### 10. 项目相关方管理

相关方参与度5个等级（从低到高）：
**不知晓 → 抵制 → 中立 → 支持 → 引领**

高频考点：
- 相关方影响力在项目**前期最大**，随项目进展逐渐降低
- 越早识别和管理相关方越好
- 相关方登记册：记录相关方信息、兴趣、期望、影响力
