# 法律法规高频考点速记

> 每年综合知识必考8-12题，背这些关键数字即可得分。

---

## 《著作权法》

| 考点 | 关键内容 |
|------|----------|
| 自然人作品保护期 | 作者**终身 + 死后50年** |
| 法人/单位作品保护期 | **发表后50年**（未发表则创作完成后50年） |
| 软件著作权保护期 | **发表后50年** |
| 合理使用（不侵权） | 个人学习研究、新闻报道引用、教学（共12种情形，不以营利为目的）|
| 职务作品（一般） | 著作权归**作者**，单位可在业务范围内优先使用 |
| 职务作品（特殊）| 著作权归**单位**（主要利用单位物质技术条件，单位承担责任的软件）|
| 软件著作权主体 | 自然人、法人、其他组织 |
| 侵权行为 | 未经许可复制、发行、翻译、改编、出租等 |

## 《专利法》

| 考点 | 关键数字 |
|------|----------|
| **发明专利**保护期 | **20年**（自申请日起）|
| **实用新型**保护期 | **10年**（自申请日起）|
| **外观设计**保护期 | **15年**（2021年修订，原为10年）|
| 申请原则 | **先申请原则**（谁先申请谁得，非先发明原则）|
| 不授予专利的情形 | 科学发现、智力活动规则和方法、疾病诊断治疗方法、动植物品种 |
| 强制许可 | 公共利益需要时，国务院可强制许可 |

## 《招标投标法》

| 考点 | 关键数字/规定 |
|------|--------------|
| 必须招标：软件采购 | ≥**50万元** |
| 必须招标：系统集成 | ≥**100万元** |
| 公开招标公告期限 | 不少于**5日** |
| 开标时间 | 投标截止时间的**同一时间**（同一地点）|
| 评标委员会规模 | **5人以上单数**，技术/经济专家不少于总数**2/3** |
| 中标候选人公示期 | **3日**以上 |
| 签订合同期限 | 中标通知书发出后**30日**内 |
| 串通投标处罚 | **3年内**不得参加依法必须招标项目的投标 |
| 转包、违规分包 | 责令改正，没收违法所得，处以罚款，情节严重吊销资质 |
| 投标保证金限额 | 不得超过招标项目估算价的**2%** |
| 履约保证金限额 | 不得超过中标合同金额的**10%** |

## 《政府采购法》

| 考点 | 关键数字/规定 |
|------|--------------|
| 公开招标限额（货物和服务） | 中央预算≥**200万元** |
| 竞争性谈判供应商数量 | 不少于**3**家 |
| 询价供应商数量 | 不少于**3**家 |
| 单一来源采购 | 只能从唯一供应商采购（特定条件下）|
| 采购代理机构 | 集中采购机构或社会代理机构 |

## 《合同法》（民法典合同编）

| 考点 | 关键内容 |
|------|----------|
| 合同成立要素 | 要约 + 承诺 |
| 合同生效条件 | 成立+当事人具有相应民事行为能力+意思表示真实+不违法公序良俗 |
| 违约金调整 | 过高可申请法院调减，过低可申请增加；超过30%可申请调整 |
| 诉讼时效 | 一般为**3年** |
| 不可抗力 | 合同解除的法定事由，发生后应及时通知对方 |
| 保密义务 | 合同履行中知悉的商业秘密，合同终止后仍需保密 |
| 合同解释优先顺序 | 通用条款 < 专用条款（专用优于通用）|

## 《网络安全法》

| 考点 | 关键内容 |
|------|----------|
| 等级保护 | 分**5个等级**，第三级以上需每年测评 |
| 网络日志留存 | 不少于**6个月** |
| 关键信息基础设施 | 数据必须在境内存储，出境需安全评估 |
| 个人信息保护 | 收集需用户同意，不得违规出售、泄露 |
| 网络安全事件报告 | 发现重大事件须及时向主管部门报告 |

---

## 《数据安全法》与《个人信息保护法》（近年新增考点）

| 考点 | 关键内容 |
|------|----------|
| 数据分类分级 | 重要数据、核心数据实行更严格保护 |
| 数据出境 | 重要数据出境须通过安全评估 |
| 个人信息处理原则 | 合法、正当、必要、最小化 |
| 敏感个人信息 | 处理须单独同意 |

## 知识产权常见陷阱题

**Q：甲公司员工利用工作时间、公司设备开发了一款软件，著作权归谁？**
A：属于特殊职务作品，著作权归**甲公司**。

**Q：A写了一本书，20年后去世，再过20年著作权还受保护吗？**
A：受保护。保护期是作者终身+死后50年，死后20年还在保护期内。

**Q：某项目需采购定制软件300万，需要招标吗？**
A：需要。软件采购≥50万元即须招标。
