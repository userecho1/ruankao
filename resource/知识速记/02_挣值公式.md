# 挣值管理（EVM）公式速记

---

## 三个基准值

| 缩写 | 全称 | 含义 |
|------|------|------|
| **PV** | 计划价值 Planned Value | 到状态日期，计划完成工作的授权预算 |
| **EV** | 挣值 Earned Value | 到状态日期，已完成工作对应的预算价值 |
| **AC** | 实际成本 Actual Cost | 到状态日期，已完成工作的实际花费 |
| **BAC** | 完工预算 Budget at Completion | 整个项目的批准总预算 |

**核心公式：EV = BAC × 已完成百分比**

---

## 偏差与绩效指数

| 指标 | 公式 | 含义 | 判断规则 |
|------|------|------|----------|
| **CV** 成本偏差 | EV - AC | 成本节省/超支金额 | >0 节省 ✓，<0 超支 ✗ |
| **SV** 进度偏差 | EV - PV | 进度超前/滞后（用金额衡量）| >0 超前 ✓，<0 滞后 ✗ |
| **CPI** 成本绩效指数 | EV / AC | 每花1元产出多少预算价值 | >1 节省 ✓，<1 超支 ✗ |
| **SPI** 进度绩效指数 | EV / PV | 计划工作量的完成比例 | >1 超前 ✓，<1 滞后 ✗ |

**口诀：差值用减（EV减另一个），比值用除（EV除另一个），EV永远在前**

---

## 完工预测

| 指标 | 公式 | 适用场景 |
|------|------|----------|
| **EAC** 完工估算 | BAC / CPI | 假设未来绩效与当前相同（最常用） |
| **EAC** 完工估算 | AC + (BAC - EV) | 假设未来工作按原计划完成（当前偏差是例外情况）|
| **EAC** 完工估算 | AC + (BAC-EV)/CPI | 综合考虑当前绩效（完整公式）|
| **ETC** 完工尚需估算 | EAC - AC | 还需要花多少钱 |
| **VAC** 完工偏差 | BAC - EAC | 完工时节省（正值）或超支（负值）多少 |
| **TCPI** 完工绩效指数 | (BAC-EV)/(BAC-AC) | 剩余工作需要达到的成本效率（>1说明要更努力）|

---

## 典型例题（必背）

**题目：** 某项目总预算（BAC）= 100万元。目前项目已完成40%，实际花费45万元，计划此时应完成50%。

**解：**
```
EV = BAC × 40% = 100 × 40% = 40万
AC = 45万（题目给出）
PV = BAC × 50% = 100 × 50% = 50万

CV = EV - AC = 40 - 45 = -5万   → 成本超支5万
SV = EV - PV = 40 - 50 = -10万  → 进度滞后（等价于10万工作量未完成）

CPI = EV/AC = 40/45 ≈ 0.89      → 每花1元只产出0.89元价值（成本效率差）
SPI = EV/PV = 40/50 = 0.80      → 只完成了计划工作的80%（进度落后）

EAC = BAC/CPI = 100/0.89 ≈ 112.4万  → 预计完工需花112.4万
ETC = EAC - AC = 112.4 - 45 = 67.4万 → 还需花67.4万
VAC = BAC - EAC = 100 - 112.4 = -12.4万 → 预计超支12.4万
```

**结论：** 该项目目前成本超支、进度滞后，若不采取措施，预计完工超支12.4万元。

## 答题模板

遇到挣值计算题，按以下格式作答：

```
（1）基础数据：
EV = BAC × 完工百分比 = ___万 × ___% = ___万
AC = ___万（题目给出）
PV = BAC × 计划完工百分比 = ___万 × ___% = ___万

（2）偏差分析：
CV = EV - AC = ___ - ___ = ___（正值=节省，负值=超支）
SV = EV - PV = ___ - ___ = ___（正值=超前，负值=滞后）
CPI = EV/AC = ___ / ___ = ___（大于1=节省，小于1=超支）
SPI = EV/PV = ___ / ___ = ___（大于1=超前，小于1=滞后）

（3）完工预测：
EAC = BAC/CPI = ___ / ___ ≈ ___万
VAC = BAC - EAC = ___ - ___ = ___万

（4）结论：
该项目目前[成本超支X万/成本节省X万]，[进度滞后/进度超前]。
预计完工总成本为___万元，[超出/低于]预算___万元。
建议[采取XXX措施]。
```
