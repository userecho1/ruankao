```
第3优先：2023年（上下半年）→ 第四版教材考点稳定后首批真题
第4优先：2022年（上下半年）→ 基础考点全覆盖
只做综合知识+案例，论文题目看标题即可（参考论文范文文件）
```

## 刷题方法（高效版）

**不要"做完整卷"，要"分类刷+立刻看解析"：**

1. 打开"练习模式"（非考试模式）
2. 做一道，立刻看解析，理解为什么错
3. 错题标记，当天复盘时重做一遍
4. 相同知识点的题连续做，加深印象

**对于综合知识：**
- 项目管理类题（约40题）→ 认真做
- 信息技术类题（约20题）→ 会就做，不会猜
- 法律法规类（约10题）→ 对照法规速记表

**对于案例分析（练习模式）：**
- 不要限时，先看题目再看参考答案
- 理解"答案结构"而非背答案
- 对照本文件夹中的答题框架，看自己的角度是否一致
