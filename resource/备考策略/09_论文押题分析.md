## 2026年论文押题方向（基于多方分析）

### 最高概率（60%以上）：整合管理

**理由**：
1. 近年新版教材（第四版）对整合管理做了较大调整
2. 2021年考过，已过去5年
3. 整合管理是"核心知识域"，最能考综合能力
4. 2026年强调"数字化转型"背景，整合管理更贴合

**应对**：背熟 [05_整合管理论文.md](../论文/05_整合管理论文.md)

---

### 次高概率（40-50%）：成本管理 / 进度管理

**成本管理**：
- 挣值管理（EVM）是高项经典考点，用于写论文最有话说
- 有具体计算例子支撑，论文内容饱满

**进度管理**：
- 关键路径、赶工、快速跟进等内容充实
- 实际项目中最常遇到的问题

## 案例分析近年考题趋势分析

### 2024-2025年案例分析主题

| 年份 | 第一题 | 第二题 | 第三题 |
|------|--------|--------|--------|
| 2025上（二批） | 整合管理（变更控制）| 进度+成本（EVM）| 风险管理 |
| 2025上（一批） | 整合管理（配置管理）| 质量管理 | 干系人管理 |
| 2024上（二批） | 整合管理（变更控制）| 进度管理（关键路径）| 采购管理 |
| 2024上（一批） | 整合管理（立项）| 成本管理（EVM）| 风险管理 |

**规律发现**：
1. **整合管理几乎每次都考**，通常是第一道大题
2. **EVM（挣值分析）每2年必考一次**（需要计算）
3. 三道题合计约75分，每道约25分
4. 通常结构：找问题（10分）+ 分析原因（10分）+ 改进措施（5分）

## 案例分析高频题型对应模板

**题型1：找出问题/错误**
→ 对照知识域规范，找出违反的地方（无需说明理由）

**题型2：请说明应该如何做**
→ 按知识域标准流程描述正确做法

**题型3：计算类（EVM/PERT/关键路径）**
→ 套公式，写过程，列清楚每一步

**题型4：进度延误原因分析**
→ 人/机/料/法/环五方面分析，每个方面1-2条

**题型5：风险应对方案**
→ 逐一列出风险，对应四种应对策略

## 沟通管理论文（补充）

> 2022下半年考过，以防万一准备一下

**摘要模板**：
> 本人参与了XX市政务服务系统建设项目，项目规模较大，涉及多个部门和外部供应商，沟通管理难度较高。在项目实施过程中，由于沟通计划不完善，信息传递不及时，导致多次项目延误。本文结合具体项目实践，从沟通规划、信息分发和沟通绩效三个方面，阐述了项目沟通管理的实施过程和取得的经验。

**正文要点**：
1. 沟通规划阶段：开展干系人分析，制定沟通管理计划（谁需要什么信息，何时，如何获取）
2. 信息分发阶段：建立信息分发矩阵，采用推式（定期报告）和交互式（协调会）相结合
3. 绩效报告：定期发送工作绩效报告（仪表盘），及时暴露问题
4. 经验教训：每阶段召开总结会，记录沟通问题并改进

## 采购/合同管理论文（补充）

**摘要模板**：
> 本人担任XX项目项目经理，该项目采购涉及多个软硬件供应商。项目实施期间，由于合同管理不规范，出现了供应商交付延迟、合同纠纷等问题，影响了项目进度。本文从采购规划、供应商选择、合同执行和采购收尾四个方面，阐述了高项采购管理的实践经验。

**正文要点**：
1. 采购规划：确定自制/外购决策，选择合同类型（范围明确→FFP，范围不明→CPIF）
2. 实施采购：发布招标文件，开展供应商评估（技术能力+商务）
3. 控制采购：定期检查供应商绩效，处理合同变更
4. 收尾采购：正式验收，付款结清，整理采购档案

## 干系人管理论文（补充）

**摘要模板**：
> 在XX项目建设中，项目涉及政府部门、业务部门、技术团队和终端用户等多方干系人，管理难度较大。项目初期，由于干系人分析不到位，部分重要干系人参与度低，导致需求频繁变更。本文结合项目实践，从干系人识别、参与度评估和参与计划三个方面阐述经验。

**正文要点**：
1. 识别干系人：建立干系人登记册，收集基本信息和利益关系
2. 分析干系人：用权力/利益矩阵分类（高权力高利益→重点管理）
3. 制定参与计划：针对不同参与度制定差异化策略（抵制→了解诉求，中立→正面引导）
4. 监督参与：定期评估参与度，调整沟通策略
