## 考试日 — 5月23日（第一批）或5月24日（第二批，以准考证为准）

> 三科同一天考完，总考试时长约6小时（含午休间隔）

### 上午场 8:30-12:30：综合知识 + 案例分析（打通240分钟）

**考前30分钟：**
- [ ] 背公式：EAC = BAC/CPI（或实际成本+剩余预算/CPI）
- [ ] 背沟通渠道：n(n-1)/2
- [ ] 默念论文背景和摘要要点

**综合知识策略（建议用时 ≤130分钟，至少120分钟后可交卷）：**
1. 先做有把握的题，遇到不确定的题目打?跳过
2. 法律法规题：不确定选最严格的那个答案
3. 挣值题：写出公式再算，检查单位
4. 剩余时间回看打?的题目，完成后直接切换案例
5. 不要改第一反应的答案（除非明确错了）

**案例分析策略（剩余时间，约110-120分钟）：**
1. 先读完全部题目，再按从熟到生的顺序作答
2. 答案要分点，每点独占一行
3. 整合管理题：必看变更控制流程是否规范
4. 风险/质量题：按规划→执行→监控三阶段分析

### 下午场 14:30-16:30：论文（120分钟，不可提前交卷）

**论文策略：**
1. 选题：优先选自己练习过的方向
2. 摘要 200 字：先写（3分钟）
3. 正文：先列提纲（5分钟），再填内容
4. 字数：2500字以上，考前计划好每段字数
5. 收尾：结论段写经验教训，体现反思
6. 注意：**不可提前交卷**，时间多余则补充细节
