问题2（9分）：中期检查时 AC、EV、PV、CV、SV 及评价

查看参考答案

根据题目给定的中期检查数据，可得：

  • AC = 70 万元
  • EV = 70 万元
  • PV = 80 万元

进一步计算：

  • CV = EV - AC = 70 - 70 = 0 万元
  • SV = EV - PV = 70 - 80 = -10 万元

绩效评价：

  • 成本方面： CV = 0，说明成本执行与计划基本一致。
  • 进度方面： SV = -10，说明项目进度落后。
  • SPI = EV / PV = 70 / 80 = 0.875，低于 1，进一步说明进度落后。
  • CPI = EV / AC = 70 / 70 = 1.0，说明成本控制正常。

结论：项目当前进度落后、成本正常。

问题3（5分）：是否需要采取纠正措施

查看参考答案

公司规定进度绩效指标、成本绩效指标在计划值的 ±10% 范围内为正常。

  • SPI = 0.875，与 1 相比偏差为 12.5%，超出允许范围。
  • CPI = 1.0，处于正常范围内。

因此：需要采取纠正措施。

可采取的措施包括：

  1. 针对关键路径上的后续活动优先配置资源，必要时采用赶工。
  2. 优化关键活动之间的衔接，在满足条件时采用快速跟进。
  3. 重点跟踪影响关键路径的活动执行情况，缩短信息反馈周期。
  4. 重新评估剩余工作计划，及时调整资源投入和实施顺序。

问题4（6分）：F 活动在 27 天内完成的概率

查看参考答案

已知 F 活动：

  • 乐观工期 O = 19 天
  • 最可能工期 M = 25 天
  • 悲观工期 P = 31 天

（1）期望工期

$$t_e = \frac{O + 4M + P}{6} = \frac{19 + 4\times25 + 31}{6} = 25 \text{ 天}$$

（2）标准差

$$\sigma = \frac{P - O}{6} = \frac{31 - 19}{6} = 2 \text{ 天}$$

（3）计算 Z 值

$$Z = \frac{27 - 25}{2} = 1.0$$

查标准正态分布表：

$$P(Z \le 1.0) = 84.13\%$$

因此：F 活动在 27 天内完成的概率约为 84.13%。
